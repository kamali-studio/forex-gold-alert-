# دیده‌بان قیمت (Price Alarm)

اپ اندروید برای نمایش قیمت لحظه‌ای فارکس، طلا (XAU/USD) و کریپتو + آلارم صوتی وقتی قیمت به هدف تعیین‌شده برسه — حتی وقتی اپ بسته‌ست.

## گرفتن کلید رایگان API

1. برو به [twelvedata.com](https://twelvedata.com/) و ثبت‌نام کن (رایگان).
2. بعد از ورود به داشبورد، کلید API رو کپی کن.
3. این کلید هم برای فارکس، هم طلا (نماد `XAU/USD`) و هم کریپتو (مثل `BTC/USD`) کار می‌کنه.
4. توجه: پلن رایگان محدودیت تعداد درخواست در دقیقه/روز داره. اپ طوری نوشته شده که همه‌ی نمادها رو با **یک درخواست** بگیره تا از این محدودیت دور بمونی، ولی بهتره فاصله‌ی چک کردن (interval) رو خیلی کوتاه نکنی (پیش‌فرض ۳۰ ثانیه مناسبه).

##   تنظیم اولیه در اپ

1. بار اول که اپ رو باز می‌کنی، کلید API که از Twelve Data گرفتی رو وارد کن.
2. توی تب "قیمت‌ها" با دکمه‌ی + هر نماد دلخواه رو اضافه کن (مثلاً `XAU/USD` برای طلا، `EUR/USD`، `BTC/USD`).
3. توی تب "آلارم‌ها":
   - کلید "مانیتورینگ پس‌زمینه" رو روشن کن — این باعث میشه یک اعلان ثابت (که قابل حذف نیست تا وقتی خاموشش کنی) نشون بده و در پس‌زمینه هر ۳۰ ثانیه قیمت‌ها رو چک کنه.
   - با دکمه‌ی + یک آلارم جدید بساز: نماد، شرط (بالاتر از / پایین‌تر از)، قیمت هدف. اگه می‌خوای بعد از فعال شدن دوباره فعال بمونه (تکرارشونده)، تیکش بزن.
4. وقتی قیمت به هدف برسه، یک نوتیفیکیشن با صدا و لرزش دریافت می‌کنی.

## نکته‌ی خیلی مهم برای گوشی‌های شیائومی/سامسونگ و مشابه

این برندها معمولاً اپ‌های پس‌زمینه رو برای صرفه‌جویی باتری می‌بندن. برای اینکه آلارم **همیشه** کار کنه:
- برو به تنظیمات گوشی > اپ‌ها > دیده‌بان قیمت > باتری، و گزینه‌ی "بدون محدودیت" یا "No restrictions" رو انتخاب کن.
- روی شیائومی (MIUI) توی "Autostart" هم اپ رو فعال کن.
- Battery Saver گوشی رو برای این اپ خاموش کن.

## محدودیت فنی مهم

قیمت‌ها از یک سرویس رایگان (Twelve Data) میاد که تأخیر کمی (چند ثانیه تا حداکثر یکی دو دقیقه بسته به نماد) نسبت به بازار واقعی داره — برای رصد و آلارم گرفتن عالیه، ولی برای اجرای معامله‌ی لحظه‌ای دقیق روش حساب نکن.
